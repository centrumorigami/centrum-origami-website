# Centrum Origami

Nowoczesna strona marketingowa dla marki Centrum Origami, zbudowana jako szybka, estetyczna i responsywna landing page w języku polskim.

## Cel

Prezentacja marki, komunikacji, oferty i wartości firmy w nowoczesny, profesjonalny sposób. Strona ma wspierać budowanie zaufania, wzmacniać wizerunek i skuteczniej przekazywać ofertę.

## Zawartość strony

- slogan: "Kreatywność w każdym zagięciu."
- sekcje: Hero, O nas, Oferta, Proces, Realizacje, Opinie, Kontakt
- opis firmy i usług
- menu nawigacyjne
- CTA i dane kontaktowe

## Uruchomienie

Wystarczy otworzyć plik `index.html` w przeglądarce lub uruchomić lokalny serwer statyczny.

Przykład:

```bash
python -m http.server 8000
```

Następnie przejdź do:

```text
http://localhost:8000
```

## Pliki

- `index.html` — struktura strony
- `styles.css` — stylizacja i układ
- `script.js` — małe interakcje
- `assets/logo.svg` — logo marki
